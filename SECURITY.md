# Security policy

## Reporting a vulnerability

Report a vulnerability privately: open the repository's **Security** tab and
choose **Report a vulnerability**. Please do not open a public issue, pull
request or discussion about it.

Include what is affected (a file, command or service), the steps to reproduce
it, and the impact you expect. We acknowledge the report, keep you informed
while we fix it, and credit you when the fix is published, unless you prefer
not to be named.
