# Product

A starter web application that grows into a small CRM, one GitHub issue at a
time, built by AI agents in this software factory.

## What exists

- **Sign-in.** Email and password, with seeded demo users, sign out and
  protected routes.
- **Dashboard.** After sign-in, a page of stat tiles and a chart, fed by one
  GraphQL query. It is the example every new feature copies: schema, resolver,
  generated types, UI, end-to-end test.

## Where it is going

A small CRM: contacts, companies, deals moving through pipeline stages,
activities and notes, search, and dashboard tiles for the pipeline. Each piece
arrives as an issue in the `crm` backlog, small enough for one agent session.

## Who it is for

Builders learning to work agent-native: they set direction and approve
designs, plans and merges; agents write, test, prove and ship the code.
